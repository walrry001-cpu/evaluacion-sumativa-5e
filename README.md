# Evaluador Relámpago — I.E. 82019 "La Florida del Inca"

App de evaluación formativa para 5.° Grado "E". Funciona 100% offline, sin servidor.

## Novedad en esta versión
Al importar preguntas desde un PDF, las opciones (a, b, c, d) YA NO se mezclan al azar:
se cargan en el mismo orden en que aparecen en el PDF, así la letra marcada como
correcta en el documento original coincide siempre con la letra correcta en la app.

## Publicar en GitHub Pages
1. Sube todos estos archivos a la raíz de tu repositorio (mantén la carpeta `icons/` tal cual).
2. Ve a Settings → Pages → Source: rama `main`, carpeta `/ (root)` → Save.
3. Tu app quedará en `https://TU-USUARIO.github.io/TU-REPOSITORIO/`.
